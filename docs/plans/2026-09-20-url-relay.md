# URL 中转实施计划

**Goal:** 在现有中转中支持 Tripo 和其他供应商，只路由 URL，其余业务内容透传。

**Architecture:** 使用 `UPSTREAM_ROUTES` JSON 对象将单段路径前缀映射到固定上游，去掉前缀后追加原始路径及查询串。保留 `UPSTREAM_BASE_URL` 单上游模式；配置路由时未知前缀返回 404，不回退。请求头仅做 HTTP 中继必要处理，正文和响应继续流式传输，不改写返回的资源 URL。

**Tech Stack:** Node.js 原生 HTTP/HTTPS、node:test，无新增依赖。

1. 在 `ls-model-midway/test/` 增加配置验证、多供应商路由、JSON/上传透传、原始 URL 保留及未知路由测试；运行 `npm test` 确认新增功能测试失败。
2. 修改 `src/server.js` 读取 `UPSTREAM_ROUTES`，修改 `src/proxy.js` 选择固定上游并剥离前缀；校验配置，拒绝非 origin-form 请求，保留单上游兼容性。
3. 更新 `.env.example` 和 README，提供 Tripo 创建/查询任务和其他供应商配置示例；说明对象存储上传及下载 URL 不会自动改写。
4. 运行完整 `npm test` 并检查最终文件。真实官方调用需要部署节点和调用方密钥，不在本地生成收费任务。
